# 项目简介

## 核心功能
- 用户登录注册
- 基于相似用户的电影推荐
- 基于相似作品的推荐
- 电影搜索
- 电影详情展示
- 电影分类浏览
- 猜你喜欢推荐
- 热门电影展示
- 用户评分
- 用户收藏
- 用户评论
- 用户管理
- 电影管理

## 适用场景
- 电影爱好者
- 电影网站
- 电影应用开发
- 文化娱乐平台

## 技术特点
- 使用 Django 框架进行后端开发
- 基于 MySQL 数据库存储数据
- 前端使用 HTML、CSS、JS 技术
- 采用协同过滤算法进行电影推荐
